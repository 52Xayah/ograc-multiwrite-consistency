# oGRAC 双节点多写一致性验证

基于已部署的 oGRAC 双节点集群，通过 DDL、DML 和跨节点并发更新实验，验证多节点读写场景下的数据可见性、事务提交及行锁等待行为。

## 项目简介

本项目围绕 oGRAC 双节点多写场景，设计并执行三个实验：

- **DDL 同步验证：** 在不同节点执行建表、删表操作，观察数据库对象的跨节点可见性。
- **DML 同步验证：** 在不同节点插入、更新和查询数据，验证已提交修改的跨节点可见性。
- **并发更新验证：** 两个节点同时更新同一行数据，观察事务提交、行锁等待及最终数据状态。

项目重点在于数据库功能验证、事务行为观察和实验结果分析，不涉及数据库内核开发或集群部署。

## 核心实验

### 1. 跨节点 DDL 可见性

在 Node0 创建测试表，在 Node1 尝试创建同名表；随后由 Node0 删除表，再由 Node1 重新创建。

**验证重点：** 不同节点对数据库对象结构变化的可见性。

### 2. 跨节点 DML 可见性

在 Node0 初始化数据，由 Node1 更新指定记录，再回到 Node0 查询更新结果。

**验证重点：** 不同节点对已提交数据修改的可见性。

### 3. 跨节点并发更新

使用两个独立会话更新同一行数据：

- Node0 将目标值修改为 55，暂不提交。
- Node1 尝试将同一记录修改为 66，观察是否发生锁等待。
- Node0 提交事务，观察 Node1 是否继续执行。
- Node1 提交后，检查最终数据。

**验证重点：** 行级锁、事务提交、锁等待及并发写入顺序。
